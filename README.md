## Before publishing

Edit `index.html` and replace:

- `YOUR_EMAIL@example.com`
- `YOUR_GITHUB`
- `YOUR_LINKEDIN`

Also replace the sample project cards with your real projects.

## Publish on GitHub Pages

1. Create a new GitHub repository, for example `portfolio`.
2. Upload `index.html`, `css/style.css`, `js/script.js`, and `README.md`.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. GitHub will publish the site at your GitHub Pages URL.

No build process is required.
